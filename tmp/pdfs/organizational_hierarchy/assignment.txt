Organizational Hierarchy Analysis
Programming Assignment
Introduction
In modern software systems, hierarchical relationships are common—from organizational structures
to file systems to category trees in e-commerce platforms. This assignment focuses on analyzing an
organizational hierarchy where employees report to supervisors in a tree structure.
Every problem in this assignment must be solved with recursion. Each function is expected to
express its traversal as a recursive walk over the hierarchy (a recursive helper function is fine);
iterative loops may be used only for bookkeeping such as building an index, iterating over a node's
children, or sorting the final result.
Dataset
You are provided with employee data in JSON format. Each employee has a unique ID, and most
employees have a supervisor_id pointing to their manager. The CEO has no supervisor
(supervisor_id: null). The dataset below contains exactly one employee with supervisor_id: null,
so the data forms a single tree rooted at the CEO.
TypeScript Interfaces
interface Employee {
  id: number;
  name: string;
  position: string;
  salary: number;
  supervisor_id: number | null;
}
interface EmployeeData {
  employees: Employee[];
}

Problem 1: Calculate Employee Depth
Description
Determine the hierarchical depth (level) of any employee in the organization. The CEO is at depth 0,
direct reports to the CEO are at depth 1, and so on.

   *

   * @param employeeId - The ID of the employee to find the depth for
   * @returns The depth level (CEO = 0), or -1 if the employee is not found
   *          or lies on a cycle
   */
  // Your implementation here
}
Input Format
employees: An array of employee objects
employeeId: An integer, the employee's unique ID
Output Format
Return an integer representing the depth level. Return -1 if the employee ID does not exist, if the
employee's supervisor chain references an ID that does not exist, or if that chain contains a cycle.
Example
getEmployeeDepth(employees, 1);   // Returns: 0  (Alice - CEO)
getEmployeeDepth(employees, 2);   // Returns: 1  (Bob - CTO)
getEmployeeDepth(employees, 7);   // Returns: 3  (Grace - Senior Developer)
getEmployeeDepth(employees, 12);  // Returns: 4  (Liam - Intern Developer)
getEmployeeDepth(employees, 999); // Returns: -1 (Not found)
Requirements
Implement using recursion: the depth of an employee is 0 for the CEO and 1 +
depth(supervisor) otherwise
Handle invalid employee IDs gracefully (return -1, do not throw)
Detect circular references (cycles) in the supervisor chain and return -1 — for example, by
passing the set of already-visited IDs down the recursion
Build an id → employee lookup (a Map) once, in O(n). The recursive walk itself must then be O(h),
where h is the height of the tree — one step per level, with no scan of the whole array per level

Problem 4: Lowest Common Manager
Description
Given two employees, find their lowest common manager—the deepest employee in the hierarchy
that is an ancestor of, or equal to, both. This is the Lowest Common Ancestor (LCA) problem on a
tree. An employee counts as its own ancestor: if one employee is an ancestor of the other, that
employee is the answer.
